# [Modulation Identification] Embarking on the Next Generation of Signal Intelligence: A Mixed Knowledge and Data-Driven Deep Learning Framework for Radio Signal Classification with Datasets Included

1. Abstractive Modulation Classification (AMC) can generally be divided into knowledge-based methods and data-driven methods. This paper explores the integration of knowledge-based methods with data-driven techniques to fully leverage their strengths, proposing a hybrid knowledge-based and data-driven deep learning framework for automatic modulation classification (HKDD). To make handcrafted features more discriminative, this paper employs various traditional features, including instantaneous features, statistical features, and spectral features. Within the HKDD framework, a feature fusion mechanism is proposed that fuses features learned from raw signals with features processed from handcrafted features through a fully connected network. Additionally, an attention mechanism is introduced on the fused features to ignore immature features and highlight important ones. To evaluate the performance of the proposed method, two datasets for modulation classification, which include both traditional features and raw IQ data, are constructed. The larger dataset contains 36 modulation categories, surpassing the number of categories in any existing automatic modulation classification dataset. Simulation results indicate that the proposed method significantly improves performance in both abundantly sampled classification scenarios and under-sampled classification scenarios.
II. Introduction With the rapid development of wireless communication technologies, various communication networks have been deployed, and intelligent terminals are gradually becoming popular. Nowadays, hundreds of millions of Internet of Things (IoT) devices have been put into use to provide wireless services, and this number is growing at an annual rate of 25%, reaching 80 billion units by 2030 [1]. The sharp increase in the number of IoT devices poses a severe challenge to spectrum resources. How to meet the growing demand for wireless services while allowing a large number of IoT devices to access the spectrum becomes a key issue. An effective method to alleviate this situation is to adopt dynamic Spectrum Access (DSA) technology based on Cognitive Radio (CR)[3,4] that allows unauthorized users to access authorized bands when authorized users are not present, thereby improving spectrum utilization efficiency. In the field of dynamic Spectrum Access, automatic Modulation Classification (AMC) has become a key technology for optimizing spectrum allocation, which can help unauthorized users detect signals from authorized users without any prior knowledge [5,6]. Once the modulation type of the authorized user is identified, unauthorized users can choose an appropriate modulation type for transmission to minimize interference with authorized users. Moreover, AMC technology is also widely used in other fields such as interference identification, communications reconnaissance, and blind signal processing.
Most traditional automatic modulation classification algorithms are designed based on domain knowledge, which may originate from statistical models or deterministic models related to theory in the fields of communication and signal processing. For example, feature-based automatic modulation classification methods design handcrafted features based on deterministic models for transmission signals of specific modulation types, while likelihood-based automatic modulation classification methods typically rely on hypothetical channel models such as additive white Gaussian noise (AWGN) channels [7]. We refer to these methods as knowledge-based approaches, which primarily rely on domain knowledge for modulation classification. Generally speaking, knowledge-based approaches do not require a large amount of training samples to learn the relationship between input and expected output because only a small number of parameters need to be estimated. However, such methods are difficult to adapt to complex and dynamically changing channel environments and tend to overly depend on selecting suitable features for different modulation types, which often are not optimal for recognizing a large number of modulation categories.
With the tremendous success of deep learning (DL) in various applications such as image recognition [8] and text classification [9], it has also been applied to radio signal processing domains, including signal detection [10], signal classification [11,12], and information restoration [13]. Data-driven deep learning methods for automatic modulation classification typically adopt supervised learning, designing deep neural networks and utilizing a large number of labeled samples for training to extract high-dimensional features from the input signals to distinguish different modulation types. Deep learning networks are generally seen as nonlinear mappings from inputs to outputs, optimizing the mapping function determined by a large number of parameters through training samples. Generally speaking, when there is sufficient training data, data-driven deep learning methods can usually achieve better performance than knowledge-based methods. However, it should be noted that deep learning models typically have many parameters, and once the training sample is insufficient, it becomes difficult to find the optimal values of model parameters, leading to a sharp decline in classification performance for deep learning-based methods under few-shot scenarios.
The next generation of artificial intelligence (AI) refers to explainable AI, which can interpret model behavior by combining domain knowledge and deeply understand its working mechanism [14]. Domain knowledge can provide constructive guidance for adjusting deep learning models to enhance relevant performance. For example, in [15], the statistical characteristics knowledge of raw data was combined with convolutional neural networks (CNN) and broad learning to design a fault diagnosis framework; in [16], handwritten Chinese characters' domain-specific knowledge (including deformation, non-linear normalization, virtual strokes, and path features) was integrated into CNN to improve the recognition performance of handwritten Chinese characters; in [17], a knowledge-driven image preprocessing module was introduced for camera recognition, extracting multi-scale knowledge from images and inputting these multi-scale knowledge along with the original images into convolutional neural networks to determine the camera type of the image. These studies demonstrate the potential of combining domain knowledge and data-driven techniques in enhancing recognition performance.
In the field of radio signal processing, we believe that the next generation of signal intelligence is a hybrid technology that combines domain knowledge with data-driven techniques, but research in this area has not yet been thoroughly explored. This paper proposes a hybrid knowledge-driven deep learning framework (HKDD) for automatic modulation classification, which achieves good performance under scenarios with sufficient labeled samples and only a few labeled samples. The knowledge considered in this paper is based on manual features studied in feature-based automatic modulation classification methods, including instantaneous features, statistical features, and spectral features. The proposed network consists of three parts: a deep learning network, a knowledge network, and a fusion network. The deep learning network provides predictions based on IQ signal inputs; the knowledge network generates predictions based on manual features inputs; the fusion network fuses the features learned from both the deep learning network and the knowledge network to generate more discriminative joint features. Two datasets were constructed to evaluate the performance of the proposed method. Overall, the contributions of this paper can be summarized as follows:
To enhance the performance of automatic modulation classification in both abundant sample and few-sample classification scenarios, the HKDD framework is proposed. By integrating the features learned from convolutional neural networks (CNN) to raw signals with the features processed by deep neural networks (DNN) from handcrafted features, the advantages of both deep learning methods and knowledge-based methods are fully leveraged.

By learning weights close to 0 to discard immature features and learning weights close to 1 to highlight important features.

The number of categories in HKDD_AMC36 is more than any existing automatic modulation classification dataset.

Dataset: To verify the performance of the proposed modulation classification method, two different datasets were generated using MATLAB (the datasets can be obtained from the specified link):
•  
HKDD_AMC12: Contains 12 different modulation signals, namely BPSK, QPSK, 8PSK, OQPSK, 16QAM, 32QAM, 64QAM, 4PAM, 8PAM, 2FSK, 4FSK, and 8FSK.

HKDD_AMC36: Contains 36 different modulation signals, including BPSK, QPSK, and other types of modulation (specific types are omitted).
In these two datasets, the raw bit sequences are randomly selected from 0 and 1 to ensure equal probability of each symbol occurrence. In HKDD_AMC36, each modulation signal has a length of 1024, while in HKDD_AMC12, it is 512. The oversampling rate is 8, therefore, in HKDD_AMC36, each sampling sequence contains 128 symbols, while in HKDD_AMC12, it contains 64 symbols. A root raised cosine (RRC) filter with a truncation length of 6 symbols is used as the pulse shaping filter, whose roll-off coefficient is randomly chosen within the range of 0.2 to 0.7. The frequency offset is randomly chosen between -0.2 and 0.2 (normalized relative to the sampling frequency). The SNR range for HKDD_AMC36 is (-20 dB, 30 dB), and for HKDD_AMC12, it is (-20 dB, 20 dB), with an interval of 2 dB. For each modulation type, the number of training samples at each SNR is 1000, and the number of test samples is half of the training samples. Both datasets contain IQ signals and traditional features, and HKDD_AMC36 is currently the dataset with the most diverse modulation categories available.
2. Model Training: The aforementioned dataset is used to train the HKDD network for classification. For HKDD_AMC36, the HKDD network serves as a 36-class classifier; for HKDD_AMC12, the output category of the HKDD network is set to 12. During training, the batch size for HKDD_AMC12 is set to 128, while that for HKDD_AMC36 is 256. The total number of parameters in the proposed HKDD network is approximately 0.1M, with the deep neural network component accounting for about 0.03M and the convolutional neural network component about 0.07M. When training the HKDD, the initial learning rate is set to 0.003, which is halved every 5 epochs. After 30 epochs of training, the network is trained using a NVIDIA GeForce RTX 2080 graphics card, taking about half an hour.
IV. Conclusion This paper proposes a hybrid knowledge-driven and data-driven deep learning framework (HKDD) for automatic modulation classification (AMC), which combines knowledge-based methods and deep learning methods, aiming to improve classification performance under both sample-rich scenarios and few-shot scenarios. To fully leverage the advantages of knowledge-based methods, various instantaneous features, statistical features, and spectral features are calculated from the raw signals. In the HKDD framework, convolutional neural networks (CNN) are used to extract features from IQ sequences, while deep neural networks (DNN) are employed to process handcrafted features. Attention mechanisms are introduced to combine learned features into joint feature vectors and design attention mechanisms to discard immature features and highlight important ones. To verify the effectiveness of the proposed method, two datasets containing both traditional features and raw IQ data for modulation classification were constructed. Simulation results show that the proposed HKDD framework outperforms both deep learning-based and knowledge-based methods in both sample-rich and few-shot scenarios, and its performance improvement is more significant as the number of training samples decreases. Moreover, the attention mechanism has been proven to be helpful in recognizing the importance of different features in few-shot scenarios training.
Despite the increasing importance of data-driven deep learning in automatic modulation classification in recent years, this paper still focuses on traditional features extracted from domain knowledge. The proposed HKDD framework emphasizes the integration of knowledge domains and data domains, providing a direction for building next-generation signal intelligence. In future work, the HKDD framework will be extended to other tasks in radio signal processing, including signal perception, signal parameter estimation, and specific radiation source identification.
